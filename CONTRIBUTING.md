# 🚀 Contributing to UniSystem AudioShare

First off, thank you for considering contributing to **UniSystem AudioShare**! 🎉 

This project is built for the open-source community, and we believe that the best ideas come from developers like you. Whether you're fixing a small bug, optimizing the Rust backend, or adding a massive new feature (like Android APK support or Dolby Surround Networking), you are welcome here!

## 🤝 How Can I Contribute?

### 1. Fix a Bug or Add a Feature
Check out our **Issues** tab. If you see something labeled `good first issue` or `help wanted`, feel free to assign yourself to it. If you have a brand new idea, just open an issue to discuss it with us before you start coding!

### 2. Improve Documentation
Did you find a typo? Is our `README.md` confusing? We love documentation fixes!

## 💻 Developer Setup Guide

To get this project running on your local machine:

1. **Prerequisites:** Make sure you have `Rust`, `Cargo`, `Node.js`, and `npm` installed.
2. **Clone the Repo:**
   ```bash
   git clone https://github.com/imuzax/UniSystem-AudioShare.git
   cd UniSystem-AudioShare
   ```
3. **Run the React Frontend (Tauri Client):**
   ```bash
   cd unisystem-tauri
   npm install
   npm run tauri dev
   ```

*(Note: Ensure you are on a Linux or Windows machine with proper audio drivers installed as we use `cpal` for hardware audio capture).*

## 🛠️ Making a Pull Request (PR)

We hate boring, long forms just as much as you do! Keep your PR simple and straight to the point:

1. **Fork** the repository and create your branch from `main`.
2. **Code** your awesome feature or bug fix.
3. **Push** your branch to your fork.
4. **Open a Pull Request** with a short, friendly explanation of what you changed. (e.g., *"Hey! I added a dark mode toggle to the dashboard!"*).

No crazy strict rules, no massive forms. Just write clean code, keep the glassmorphism vibes intact, and let's build something awesome together! 🚀
